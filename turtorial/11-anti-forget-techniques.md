# Ky thuat tranh AI "quen" trong task dai

- Tach task thanh phase:
  - Phase 1: Read-only + root cause
  - Phase 2: Implement trong pham vi
  - Phase 3: Analyze/Test + report
- Moi phase nhac lai rang buoc scope.
- Dat Definition of Done ngay tu dau.
- Paste log/stacktrace that thay vi mo ta chung chung.
- Neu task dai, yeu cau cap nhat checklist theo tung buoc.
