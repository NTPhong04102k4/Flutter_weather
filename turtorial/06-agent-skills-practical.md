# Agent skills ap dung thuc te

- `babysit`: giu PR merge-ready, xu ly comment/conflict/CI.
- `create-rule`: tao rule de AI tuan thu coding convention.
- `create-skill`: dong goi workflow lap lai cua team.
- `update-cursor-settings`: toi uu `settings.json`.
- `update-cli-config`: toi uu `cli-config.json`.
- `canvas`: dung cho noi dung truc quan.

Khuyen nghi nhanh:

1. Tao rule Flutter chung bang `create-rule`.
2. Dung `babysit` khi vao giai doan PR.
3. Dong goi task lap lai bang `create-skill`.
