# Tham chiếu CLI

> Tham chiếu đầy đủ cho giao diện dòng lệnh của Claude Code, bao gồm các lệnh và cờ (flag).

## Các lệnh CLI

Bạn có thể bắt đầu phiên làm việc, đưa nội dung qua pipe, tiếp tục các cuộc hội thoại và quản lý cập nhật bằng các lệnh sau:

| Lệnh                         | Mô tả                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Ví dụ                                                     |
| :------------------------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------- |
| `claude`                        | Bắt đầu phiên tương tác                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | `claude`                                                    |
| `claude "query"`                | Bắt đầu phiên tương tác với prompt khởi tạo                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | `claude "explain this project"`                             |
| `claude -p "query"`             | Gửi truy vấn qua SDK, rồi thoát                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `claude -p "explain this function"`                         |
| `cat file \| claude -p "query"` | Xử lý nội dung được đưa qua pipe                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | `cat logs.txt \| claude -p "explain"`                       |
| `claude -c`                     | Tiếp tục cuộc hội thoại gần nhất trong thư mục hiện tại                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | `claude -c`                                                 |
| `claude -c -p "query"`          | Tiếp tục qua SDK                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | `claude -c -p "Check for type errors"`                      |
| `claude -r "<session>" "query"` | Tiếp tục phiên theo ID hoặc tên                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | `claude -r "auth-refactor" "Finish this PR"`                |
| `claude update`                 | Cập nhật lên phiên bản mới nhất                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `claude update`                                             |
| `claude gateway`                | Khởi động máy chủ [Claude apps gateway](/en/claude-apps-gateway) tự lưu trữ (self-hosted), dành cho quản trị viên triển khai SSO và chính sách trước Claude Code trên Amazon Bedrock, Google Cloud's Agent Platform, hoặc Microsoft Foundry. Yêu cầu `--config` trỏ tới [`gateway.yaml`](/en/claude-apps-gateway-config). Có sẵn từ Claude Code v2.1.195 trở lên.                                                                                                                                                                                                                                                                | `claude gateway --config gateway.yaml`                      |
| `claude install [version]`      | Cài đặt hoặc cài lại binary gốc (native). Chấp nhận một phiên bản như `2.1.118`, hoặc `stable` hoặc `latest`. Xem [Cài đặt một phiên bản cụ thể](/en/setup#install-a-specific-version)                                                                                                                                                                                                                                                                                                                                                | `claude install stable`                                     |
| `claude auth login`             | Đăng nhập vào tài khoản Anthropic của bạn. Dùng `--email` để điền sẵn địa chỉ email, `--sso` để buộc xác thực SSO, và `--console` để đăng nhập bằng Anthropic Console cho việc thanh toán theo mức sử dụng API thay vì gói đăng ký (subscription) Claude                                                                                                                                                                                                                                                                                           | `claude auth login --console`                               |
| `claude auth logout`            | Đăng xuất khỏi tài khoản Anthropic của bạn                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | `claude auth logout`                                        |
| `claude auth status`            | Hiển thị trạng thái xác thực dưới dạng JSON. Dùng `--text` để có kết quả dễ đọc cho người. Thoát với mã 0 nếu đã đăng nhập, 1 nếu chưa                                                                                                                                                                                                                                                                                                                                                                                                     | `claude auth status`                                        |
| `claude agents`                 | Mở [agent view](/en/agent-view) để theo dõi và điều phối các phiên nền (background) chạy song song. Dùng `--cwd <path>` để chỉ hiển thị các phiên khởi động dưới thư mục đó, hoặc `--json` để in các phiên đang hoạt động dưới dạng mảng JSON phục vụ scripting (`--json --all` cũng bao gồm cả các phiên nền đã hoàn thành). Truyền `--permission-mode`, `--model`, `--effort`, hoặc `--agent` để đặt [giá trị mặc định cho các phiên được điều phối](/en/agent-view#permission-mode-model-and-effort). Chấp nhận `--settings`, `--add-dir`, `--plugin-dir`, và `--mcp-config` giống như lệnh `claude` cấp cao nhất. Mở agent view yêu cầu một terminal tương tác | `claude agents --json`                                      |
| `claude attach <id>`            | Gắn vào một [phiên nền](/en/agent-view#manage-sessions-from-the-shell) trong terminal này                                                                                                                                                                                                                                                                                                                                                                                                                                         | `claude attach 7c5dcf5d`                                    |
| `claude auto-mode defaults`     | In các quy tắc classifier tích hợp sẵn của [auto mode](/en/permission-modes#eliminate-prompts-with-auto-mode) dưới dạng JSON. Dùng `claude auto-mode config` để xem cấu hình hiệu lực của bạn sau khi áp dụng settings                                                                                                                                                                                                                                                                                                                    | `claude auto-mode defaults > rules.json`                    |
| `claude daemon status`          | In trạng thái, phiên bản, thư mục socket và số lượng worker của [tiến trình giám sát (supervisor)](/en/agent-view#the-supervisor-process) phiên nền phục vụ chẩn đoán. Thoát với 1 nếu supervisor không chạy                                                                                                                                                                                                                                                                                                                                                                                                                              | `claude daemon status`                                     |
| `claude daemon stop --any`      | Dừng [supervisor](/en/agent-view#the-supervisor-process) phiên nền cùng các phiên mà nó lưu trữ. Truyền `--keep-workers` để giữ các phiên nền tiếp tục chạy để supervisor kế tiếp kết nối lại với chúng. `--any` xác nhận việc dừng một supervisor theo yêu cầu (on-demand), vốn là mặc định. Dùng lệnh này để khôi phục từ một [supervisor không phản hồi](/en/agent-view#agent-view-says-the-background-service-did-not-respond)                                                                                                                                                                                                   | `claude daemon stop --any --keep-workers`                  |
| `claude logs <id>`              | In kết quả gần đây từ một [phiên nền](/en/agent-view#manage-sessions-from-the-shell)                                                                                                                                                                                                                                                                                                                                                                                                                                           | `claude logs 7c5dcf5d`                                     |
| `claude mcp`                    | Cấu hình các máy chủ Model Context Protocol (MCP)                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | Xem [tài liệu MCP của Claude Code](/en/mcp).           |
| `claude mcp login <name>`       | {/* min-version: 2.1.186 */}Chạy luồng OAuth của một máy chủ MCP đã cấu hình mà không cần mở bảng `/mcp` tương tác. Hoạt động với các máy chủ HTTP, SSE, và connector claude.ai. Thêm `--no-browser` khi dùng qua SSH để in URL ủy quyền thay vì mở trình duyệt, rồi dán URL chuyển hướng trở lại tại dấu nhắc. Yêu cầu Claude Code v2.1.186 trở lên. Xem [Xác thực từ dòng lệnh](/en/mcp#authenticate-from-the-command-line)                                                                                                                                                                           | `claude mcp login sentry`                                   |
| `claude mcp logout <name>`      | {/* min-version: 2.1.186 */}Xóa thông tin xác thực OAuth đã lưu cho một máy chủ MCP. Yêu cầu Claude Code v2.1.186 trở lên                                                                                                                                                                                                                                                                                                                                                                                                     | `claude mcp logout sentry`                                 |
| `claude plugin`                 | Quản lý [plugin](/en/plugins) của Claude Code. Bí danh (alias): `claude plugins`. Xem [tham chiếu plugin](/en/plugins-reference#cli-commands-reference) để biết các lệnh con                                                                                                                                                                                                                                                                                                                                                                                                                                 | `claude plugin install code-review@claude-plugins-official` |
| `claude project purge [path]`   | Xóa toàn bộ trạng thái Claude Code cục bộ cho một dự án: transcript, danh sách công việc, log gỡ lỗi, lịch sử chỉnh sửa file, các dòng lịch sử prompt, và mục của dự án trong `~/.claude.json`. Bỏ qua `[path]` để chọn từ danh sách tương tác. Cờ: `--dry-run` để xem trước, `-y`/`--yes` để bỏ qua xác nhận, `-i`/`--interactive` để xác nhận từng mục, `--all` cho mọi dự án. Xem [Xóa dữ liệu cục bộ](/en/claude-directory#clear-local-data)                                                                                                                                                                                       | `claude project purge ~/work/repo --dry-run`                |
| `claude remote-control`         | Khởi động một máy chủ [Remote Control](/en/remote-control) để điều khiển Claude Code từ Claude.ai hoặc ứng dụng Claude. Chạy ở chế độ máy chủ (không có phiên tương tác cục bộ). Xem [Các cờ chế độ máy chủ](/en/remote-control#start-a-remote-control-session)                                                                                                                                                                                                                                                                                                                                                                              | `claude remote-control --name "My Project"`                 |
| `claude respawn <id>`           | Khởi động lại một [phiên nền](/en/agent-view#manage-sessions-from-the-shell), đang chạy hoặc đã dừng, với cuộc hội thoại còn nguyên vẹn. Dùng `--all` để khởi động lại mọi phiên đang chạy, ví dụ để áp dụng một binary Claude Code đã cập nhật                                                                                                                                                                                                                                                                                             | `claude respawn 7c5dcf5d`                                   |
| `claude rm <id>`                | Gỡ một [phiên nền](/en/agent-view#manage-sessions-from-the-shell) khỏi danh sách. Transcript của cuộc hội thoại vẫn nằm trên máy cục bộ của bạn, có thể truy cập qua `claude --resume`                                                                                                                                                                                                                                                                                                                                                 | `claude rm 7c5dcf5d`                                        |
| `claude setup-token`            | Tạo một token OAuth tồn tại lâu dài cho CI và scripts. In token ra terminal mà không lưu lại. Yêu cầu một gói đăng ký Claude. Xem [Tạo token tồn tại lâu dài](/en/authentication#generate-a-long-lived-token)                                                                                                                                                                                                                                                                                                                                                                                                              | `claude setup-token`                                       |
| `claude stop <id>`              | Dừng một [phiên nền](/en/agent-view#manage-sessions-from-the-shell). Cũng chấp nhận `claude kill`                                                                                                                                                                                                                                                                                                                                                                                                                                   | `claude stop 7c5dcf5d`                                      |
| `claude ultrareview [target]`   | Chạy [ultrareview](/en/ultrareview#run-ultrareview-non-interactively) ở chế độ không tương tác. In các phát hiện ra stdout và thoát với 0 khi thành công hoặc 1 khi thất bại. Dùng `--json` cho payload thô và `--timeout <minutes>` để ghi đè mặc định 30 phút                                                                                                                                                                                                                                                                   | `claude ultrareview 1234 --json`                            |

Nếu bạn gõ sai một lệnh con, Claude Code gợi ý lệnh gần đúng nhất và thoát mà không bắt đầu phiên. Ví dụ, `claude udpate` in ra `Did you mean claude update?`.

{/* min-version: 2.1.199 */}Kể từ v2.1.199, `claude --dangerously-skip-permissions daemon <subcommand>` chạy lệnh con `daemon`. Các phiên bản trước xem `daemon <subcommand>` như prompt cho một phiên tương tác mới, nên lệnh con không bao giờ chạy khi cờ đứng trước, một thiết lập phổ biến khi `claude` được đặt bí danh (alias) kèm theo cờ. Chỉ một `--dangerously-skip-permissions` hoặc `--allow-dangerously-skip-permissions` đứng đầu mới định tuyến tới `daemon` theo cách này; bất kỳ cờ nào khác đứng đầu vẫn khởi động một phiên tương tác.

## Các cờ CLI

Tùy chỉnh hành vi của Claude Code bằng các cờ dòng lệnh sau. `claude --help` không liệt kê mọi cờ, nên việc một cờ vắng mặt trong `--help` không có nghĩa là nó không khả dụng.

| Cờ                                            | Mô tả                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Ví dụ                                                                                             |
| :---------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------- |
| `--add-dir`                                     | Thêm các thư mục làm việc bổ sung để Claude đọc và chỉnh sửa file. Cấp quyền truy cập file; hầu hết cấu hình `.claude/` [không được phát hiện](/en/permissions#additional-directories-grant-file-access-not-configuration) từ các thư mục này. Xác thực rằng mỗi đường dẫn tồn tại như một thư mục. Để lưu các thư mục này qua các phiên, đặt [`permissions.additionalDirectories`](/en/settings#permission-settings) trong settings                                                                                                                                                                                                                                                                                                                                                                                                                                            | `claude --add-dir ../apps ../lib`                                                                   |
| `--advisor <model>`                             | {/* min-version: 2.1.98 */}Bật công cụ [advisor](/en/advisor) phía máy chủ cho phiên này với một alias model: `opus`, `sonnet`, hoặc `fable` ({/* min-version: 2.1.170 */}v2.1.170+), hoặc một model ID đầy đủ. Ưu tiên hơn setting `advisorModel` cho phiên. Yêu cầu Claude Code v2.1.98 trở lên                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | `claude --advisor opus`                                                                             |
| `--agent`                                       | Chỉ định một agent cho phiên hiện tại (ghi đè setting `agent`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | `claude --agent my-custom-agent`                                                                    |
| `--agents`                                      | Định nghĩa các subagent tùy chỉnh một cách động qua JSON. Dùng cùng tên trường như [frontmatter](/en/sub-agents#supported-frontmatter-fields) của subagent, cộng thêm một trường `prompt` cho hướng dẫn của agent                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | `claude --agents '{"reviewer":{"description":"Reviews code","prompt":"You are a code reviewer"}}'`  |
| `--allow-dangerously-skip-permissions`          | Thêm `bypassPermissions` vào chu trình chuyển chế độ `Shift+Tab` mà không khởi động ở chế độ đó. Cho phép bạn bắt đầu ở một chế độ khác như `plan` rồi chuyển sang `bypassPermissions` sau. Xem [permission modes](/en/permission-modes#skip-all-checks-with-bypasspermissions-mode)                                                                                                                                                                                                                                                                                                                                                                                                                          | `claude --permission-mode plan --allow-dangerously-skip-permissions`                                |
| `--allowedTools`, `--allowed-tools`             | Các tool thực thi mà không cần hỏi quyền. Xem [cú pháp quy tắc quyền](/en/settings#permission-rule-syntax) để biết cách khớp mẫu. Để giới hạn những tool nào khả dụng, dùng `--tools` thay thế                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | `"Bash(git log *)" "Bash(git diff *)" "Read"`                                                       |
| `--append-system-prompt`                        | Thêm văn bản tùy chỉnh vào cuối system prompt mặc định                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | `claude --append-system-prompt "Always use TypeScript"`                                             |
| `--append-system-prompt-file`                   | Nạp thêm văn bản system prompt từ một file và thêm vào prompt mặc định                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | `claude --append-system-prompt-file ./extra-rules.txt`                                              |
| `--ax-screen-reader`                            | {/* min-version: 2.1.181 */}Kết xuất kết quả thân thiện với trình đọc màn hình: văn bản phẳng, không viền trang trí hay hoạt ảnh. Buộc dùng bộ kết xuất cổ điển (classic renderer), nên setting [`tui`](/en/settings#available-settings) không có tác dụng cho phiên. Ưu tiên hơn [`CLAUDE_AX_SCREEN_READER`](/en/env-vars) và setting [`axScreenReader`](/en/settings#available-settings). Yêu cầu Claude Code v2.1.181 trở lên                                                                                                                                                                                                                                                                                                                                                                                                                                       | `claude --ax-screen-reader`                                                                         |
| `--bare`                                        | Chế độ tối giản: bỏ qua tự động phát hiện hook, skill, plugin, máy chủ MCP, auto memory, và CLAUDE.md để các lệnh scripted khởi động nhanh hơn. Claude có quyền truy cập tool Bash, đọc file, và chỉnh sửa file. Đặt [`CLAUDE_CODE_SIMPLE`](/en/env-vars). Xem [bare mode](/en/headless#start-faster-with-bare-mode)                                                                                                                                                                                                                                                                                        | `claude --bare -p "query"`                                                                          |
| `--betas`                                       | Các header beta để đưa vào các yêu cầu API (chỉ dành cho người dùng API key)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | `claude --betas interleaved-thinking`                                                               |
| `--bg`, `--background`                          | Khởi động phiên như một [background agent](/en/agent-view) và trả về ngay lập tức. In session ID và các lệnh quản lý. Kết hợp với `--exec` để chạy một lệnh shell dưới dạng công việc nền thay vì một phiên Claude, hoặc với `--agent` để chạy một subagent cụ thể. {/* min-version: 2.1.198 */}Không thể kết hợp với `-p`/`--print`; xem [tham chiếu lỗi](/en/errors#command-line-errors)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | `claude --bg "investigate the flaky test"`                                                          |
| `--channels`                                    | (Bản xem trước nghiên cứu) Các máy chủ MCP mà Claude nên lắng nghe thông báo [channel](/en/channels) của chúng trong phiên này. Danh sách các mục `plugin:<name>@<marketplace>` ngăn cách bằng dấu cách. Yêu cầu xác thực Claude.ai                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | `claude --channels plugin:my-notifier@my-marketplace`                                               |
| `--chrome`                                      | Bật [tích hợp trình duyệt Chrome](/en/chrome) để tự động hóa và kiểm thử web                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | `claude --chrome`                                                                                   |
| `--cloud`                                       | Tạo một [phiên web](/en/claude-code-on-the-web) mới trên claude.ai với mô tả công việc được cung cấp                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | `claude --cloud "Fix the login bug"`                                                                |
| `--continue`, `-c`                              | Nạp cuộc hội thoại gần nhất trong thư mục hiện tại. Bao gồm các phiên đã thêm thư mục này bằng `/add-dir`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | `claude --continue`                                                                                 |
| `--dangerously-load-development-channels`       | Bật các [channel](/en/channels-reference#test-during-the-research-preview) không nằm trong danh sách cho phép đã duyệt, dùng cho phát triển cục bộ. Chấp nhận các mục `plugin:<name>@<marketplace>` và `server:<name>`. Hỏi xác nhận                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | `claude --dangerously-load-development-channels server:webhook`                                     |
| `--dangerously-skip-permissions`                | Bỏ qua các dấu nhắc quyền. Tương đương với `--permission-mode bypassPermissions`. Xem [permission modes](/en/permission-modes#skip-all-checks-with-bypasspermissions-mode) để biết điều này bỏ qua và không bỏ qua những gì                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `claude --dangerously-skip-permissions`                                                             |
| `--debug`                                       | Bật chế độ gỡ lỗi với lọc theo danh mục tùy chọn (ví dụ, `"api,hooks"` hoặc `"!statsig,!file"`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | `claude --debug "api,mcp"`                                                                          |

### Các cờ system prompt

Claude Code cung cấp bốn cờ để tùy chỉnh system prompt. Cả bốn đều hoạt động ở cả chế độ tương tác lẫn không tương tác.

| Cờ                          | Hành vi                                    | Ví dụ                                                 |
| :---------------------------- | :------------------------------------------ | :------------------------------------------------------ |
| `--system-prompt`             | Thay thế toàn bộ prompt mặc định          | `claude --system-prompt "You are a Python expert"`      |
| `--system-prompt-file`        | Thay thế bằng nội dung file                 | `claude --system-prompt-file ./prompts/review.txt`      |
| `--append-system-prompt`      | Thêm vào prompt mặc định               | `claude --append-system-prompt "Always use TypeScript"` |
| `--append-system-prompt-file` | Thêm nội dung file vào prompt mặc định | `claude --append-system-prompt-file ./style-rules.txt`  |

`--system-prompt` và `--system-prompt-file` loại trừ lẫn nhau. Các cờ append có thể được kết hợp với một trong hai cờ thay thế.

Chọn dựa trên việc bản sắc mặc định của Claude Code có còn phù hợp với công việc của bạn hay không. Dùng một cờ append khi Claude nên vẫn là một trợ lý lập trình đồng thời tuân theo các quy tắc bổ sung của bạn: các hướng dẫn theo từng lần gọi, định dạng kết quả, hoặc ngữ cảnh miền cho một script `-p`. Việc append giữ nguyên hướng dẫn tool mặc định, các hướng dẫn an toàn, và các quy ước lập trình, nên bạn chỉ cung cấp những gì khác biệt. Dùng một cờ thay thế khi bề mặt, bản sắc, hoặc mô hình quyền khác với của Claude Code, như một agent không lập trình trong một pipeline mà không có con người nào theo dõi. Việc thay thế loại bỏ toàn bộ prompt mặc định, bao gồm hướng dẫn tool và các hướng dẫn an toàn, nên bạn chịu trách nhiệm cho bất cứ điều gì mà công việc của bạn vẫn cần.

Các cờ này chỉ áp dụng cho lần gọi hiện tại. Đối với các persona bền vững mà bạn có thể chuyển đổi giữa chúng và chia sẻ trong một dự án, dùng [output styles](/en/output-styles).
