# Tuần 23 · 1–5 tháng 6, 2026

  <p className="digest-feature-lede">Auto mode giờ đã có mặt trên Amazon Bedrock, Agent Platform của Google Cloud, và Microsoft Foundry cho Opus 4.7 và Opus 4.8, thay thế các lời nhắc xin phép bằng các kiểm tra an toàn chạy nền trên các nhà cung cấp bên thứ ba. Tham gia (opt in) bằng cách đặt <code>CLAUDE\_CODE\_ENABLE\_AUTO\_MODE=1</code>.</p>

  <p className="digest-feature-try">Tham gia trên một nhà cung cấp bên thứ ba, rồi xoay vòng tới auto mode bằng Shift+Tab:</p>

  ```bash terminal theme={null}
  export CLAUDE_CODE_ENABLE_AUTO_MODE=1
  ```

  <a className="digest-feature-link" href="/docs/en/permission-modes#enable-auto-mode-on-bedrock-agent-platform-or-foundry">Bật auto mode trên các nhà cung cấp bên thứ ba</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Chỉnh sửa tự động an toàn hơn</span>
    <span className="digest-feature-pill">v2.1.160</span>
  </div>

  <p className="digest-feature-lede">Claude Code giờ nhắc trước khi ghi các file có thể chạy mã, ngay cả trong chế độ <code>acceptEdits</code>. Tập hợp được bảo vệ bao gồm các file khởi động shell như <code>.zshenv</code> và <code>.bash\_login</code>, cấu hình git dưới <code>\~/.config/git/</code>, và các cấu hình công cụ build như <code>.npmrc</code>, <code>.bazelrc</code>, và <code>.pre-commit-config.yaml</code>. Các thao tác ghi này không bao giờ được tự động phê duyệt ở bất kỳ chế độ nào ngoại trừ <code>bypassPermissions</code>.</p>

  <p className="digest-feature-try">Làm việc ở chế độ acceptEdits; Claude giờ tạm dừng trước khi ghi các file này:</p>

  ```bash terminal theme={null}
  claude --permission-mode acceptEdits
  ```

  <a className="digest-feature-link" href="/docs/en/permission-modes#protected-paths">Các đường dẫn được bảo vệ</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Liệt kê các plugin đã cài với /plugin list</span>
    <span className="digest-feature-pill">v2.1.163</span>
  </div>

  <p className="digest-feature-lede">Lệnh mới <code>/plugin list</code> in các plugin đã cài của bạn ngay tại chỗ (inline), mà không cần mở menu <code>/plugin</code>, và cũng có sẵn dưới dạng <code>claude plugin list</code> từ shell. Ở dạng tương tác, thêm `--enabled` hoặc `--disabled` để chỉ hiển thị các plugin ở trạng thái đó.</p>

  <p className="digest-feature-try">Liệt kê các plugin hiện đang được bật:</p>

  ```text Claude Code theme={null}
  > /plugin list --enabled
  ```

  <a className="digest-feature-link" href="/docs/en/plugins-reference#plugin-list">Các lệnh plugin</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">Yêu cầu phiên bản cho các triển khai được quản lý</span>

  </div>

  <p className="digest-feature-lede">Hai cài đặt được quản lý, <code>requiredMinimumVersion</code> và <code>requiredMaximumVersion</code>, cho phép tổ chức của bạn yêu cầu một khoảng phiên bản Claude Code đã được phê duyệt. Một client nằm ngoài khoảng đó sẽ thoát khi khởi động và báo cho người dùng cập nhật qua phương thức của tổ chức. <code>claude update</code>, <code>claude install</code>, và <code>claude doctor</code> vẫn tiếp tục hoạt động để người dùng có thể khắc phục.</p>

  <p className="digest-feature-try">Thêm một mức sàn vào các cài đặt được quản lý để các client cũ hơn từ chối khởi động:</p>

  ```json managed-settings.json theme={null}
  {
    "requiredMinimumVersion": "2.1.163"
  }
  ```

  <a className="digest-feature-link" href="/docs/en/admin-setup#decide-what-to-enforce">Quyết định điều cần thực thi</a>
</div>
